# FairTeam AI
學生小組專題公平貢獻分析與衝突調解助手

## 一、作品名稱與簡介
**作品名稱**：FairTeam AI  
**英文名稱**：FairTeam AI - Fair Contribution Analysis & Conflict Mediation Assistant for Student Group Projects

本作品是一套專為學生小組專題設計的智慧分析工具。透過整合 GitHub 程式碼貢獻紀錄與聊天/會議文字資料，自動計算每位組員的實際貢獻程度，並由大型語言模型生成可解釋的貢獻報告與具體調解建議，協助學生解決小組合作中最常見的「貢獻不均」與「衝突難以調解」問題。

## 二、問題背景與動機
在大專院校與高中職的專題課程中，小組合作幾乎是必修環節。然而，實務上經常出現以下情況：
- 部分組員幾乎不參與實際工作，卻共享相同分數
- 聊天群組很活躍的人，實際程式碼貢獻卻很少
- 真正付出最多的同學感到不公平，卻缺乏客觀證據
- 老師難以從最終成果判斷個別貢獻

這些問題不僅影響學習公平性，也容易造成組內衝突與學習意願下降。現有工具多半只針對老師端評分，或僅分析 Git commit，無法同時考慮溝通與執行層面。

因此，我們開發 FairTeam AI，讓「學生自己」就能快速獲得客觀、可解釋的貢獻分析。

## 三、解決方案與創新點
### 核心解決方案
1. 多維度貢獻分析（程式碼 + 溝通 + 任務執行）
2. 使用 Gini 係數量化不公平程度
3. 大型語言模型生成個人化貢獻摘要與調解建議
4. 強調隱私與去識別化設計

### 創新點
- 同時整合程式碼貢獻與文字溝通紀錄
- 提供「可執行的調解建議」而非只給分數
- 以學生自用為核心設計，而非僅供教師評分
- 完整考慮資料隱私與倫理問題

## 四、系統功能
1. GitHub Repo 分析
2. 聊天/會議紀錄分析
3. 多維度公平分數計算
4. 不公平程度視覺化（Gini 係數）
5. AI 生成報告與調解建議
6. 一鍵匯出 Markdown 報告

## 五、技術架構
- 前端：Streamlit
- Git 分析：PyDriller、GitPython
- 資料處理：Pandas、NumPy
- 公平計算：自訂多維度加權 + Gini 係數
- 報告生成：Google Gemini / OpenAI API（可選）
- 視覺化：Plotly

## 六、實驗與驗證
我們使用模擬小組資料與真實小型專案進行測試，驗證系統能有效識別貢獻不均情況，並產生具參考價值的調解建議。

## 七、社會影響與未來展望
本作品期望降低學生小組合作中的不公平感與衝突，培養更健康的協作文化。未來可擴充支援更多平台（GitLab、Notion、Discord）與更細緻的任務追蹤功能。
