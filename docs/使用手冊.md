# FairTeam AI 使用手冊

## 安裝與啟動
1. 安裝 Python 3.9 以上版本
2. 建立虛擬環境並安裝套件：
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. 執行 `streamlit run src/app.py`

## 操作步驟
1. 在左側輸入 GitHub Repo 路徑
2. 上傳聊天或會議紀錄（txt 格式）
3. 填寫組員名單
4. 點擊「開始分析」
5. 查看結果並下載報告

## 聊天紀錄格式建議
```
王小明: 我今天把登入功能寫完了
陳小華: 我負責測試，目前發現一個 bug
林小美: 簡報我來做
```

## 注意事項
- 組員名字需與 Git 作者名稱或聊天發言者盡量一致，系統才會正確對應
- 建議先使用自己的小型專案測試
