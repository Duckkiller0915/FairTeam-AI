# 倫理與隱私說明

## 資料使用原則
本系統設計時優先考慮學生資料隱私：

1. 所有分析預設在本地端執行，不會自動上傳資料到外部伺服器。
2. 聊天紀錄建議使用者先自行去識別化（移除真實姓名、學號、敏感內容）。
3. 系統不會永久儲存使用者上傳的檔案。
4. 若使用雲端 LLM API，僅會傳送去識別後的統計摘要與必要文字，不會傳送完整原始聊天內容（可自行控制）。

## 使用建議
- 僅分析自己有權限的 Repo 與聊天紀錄
- 產生報告後，與組員共同檢視再決定是否提交給老師
- 本工具僅作為參考依據，最終評分權仍屬於指導教師

## 限制說明
- 無法完美判斷「思考貢獻」或「線下討論」
- 名稱比對依賴使用者輸入的一致性
- 僅供學習與輔助用途
